# 🌟 Портфолио Aidana Akunova

Современное и профессиональное IT-портфолио для начинающего Frontend-разработчика, созданное с использованием чистого HTML, CSS и JavaScript.

## 🚀 Особенности

- ✨ **Современный дизайн** с фиолетовыми градиентами и плавными анимациями
- 🌓 **Переключатель темы** (тёмная/светлая) с сохранением выбора
- 📱 **Полностью адаптивный** дизайн для всех устройств
- 🎨 **Красивые визуальные эффекты** и градиентные элементы
- ⚡ **Быстрая загрузка** без внешних зависимостей
- 🎯 **SEO-оптимизация** и семантическая разметка
- ♿ **Доступность** (accessibility) для всех пользователей

## 📄 Страницы

1. **Главная (index.html)** - Приветствие, краткая информация, навыки и проекты
2. **Обо мне (about.html)** - Подробная информация о разработчике, цели и увлечения
3. **Навыки (skills.html)** - Детальное описание технических навыков с прогресс-барами
4. **Проекты (projects.html)** - 8 мини-проектов с описаниями:
   - Tic-Tac-Toe
   - Dark Mode
   - Calculator
   - Memory Game
   - Drawing App
   - Rock Paper Scissors
   - Pomodoro Timer
   - Quiz App
5. **Контакты (contact.html)** - Способы связи через Telegram и GitHub
6. **Политика конфиденциальности (privacy.html)** - Информация о защите данных

## 🛠️ Технологии

- **HTML5** - Семантическая разметка
- **CSS3** - Flexbox, Grid, анимации, градиенты
- **JavaScript (ES6+)** - Интерактивность и функциональность
- **Без библиотек** - Чистый код без React, Bootstrap и др.

## 🚀 Быстрый старт

### Локальный запуск

1. Клонируйте репозиторий или скачайте файлы
2. Откройте `index.html` в браузере
3. Готово! Сайт работает без дополнительной настройки

### Запуск с локальным сервером (рекомендуется)

```bash
# Используя Python 3
python -m http.server 8000

# Используя Node.js (если установлен npx)
npx serve

# Используя PHP
php -S localhost:8000
```

Затем откройте `http://localhost:8000` в браузере.

## 🌐 Публикация на Vercel

### Способ 1: Через GitHub (рекомендуется)

1. Создайте репозиторий на GitHub
2. Загрузите все файлы в репозиторий:

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/keshhha01/aidana-portfolio.git
git push -u origin main
```

3. Перейдите на [vercel.com](https://vercel.com)
4. Нажмите "New Project"
5. Импортируйте ваш GitHub репозиторий
6. Нажмите "Deploy"
7. Готово! Ваш сайт опубликован

### Способ 2: Через Vercel CLI

```bash
# Установите Vercel CLI
npm install -g vercel

# В папке проекта выполните
vercel

# Следуйте инструкциям в терминале
```

### Способ 3: Drag & Drop

1. Перейдите на [vercel.com](https://vercel.com)
2. Перетащите папку проекта в окно браузера
3. Готово!

## ⚙️ Настройка

### Замена Telegram username

В файлах найдите `YOUR_TELEGRAM_USERNAME` и замените на ваш настоящий username:

```html
<!-- Найти и заменить во всех HTML файлах -->
<a href="https://t.me/YOUR_TELEGRAM_USERNAME">
<!-- Заменить на -->
<a href="https://t.me/your_real_username">
```

Файлы для замены:
- `index.html`
- `about.html`
- `skills.html`
- `projects.html`
- `contact.html`
- `privacy.html`

### Добавление ссылок на проекты

В файле `projects.html` найдите кнопки "GitHub" и замените `#` на реальные ссылки:

```html
<a href="#" class="btn btn-small btn-outline" onclick="...">
<!-- Заменить на -->
<a href="https://github.com/keshhha01/project-name" class="btn btn-small btn-outline" target="_blank">
```

### Изменение цветовой схемы

В файле `style.css` измените CSS-переменные:

```css
:root {
    --accent-primary: #a855f7;     /* Основной цвет */
    --accent-secondary: #ec4899;   /* Второстепенный цвет */
    --accent-tertiary: #3b82f6;    /* Дополнительный цвет */
}
```

## 🎨 Функциональность

### Переключатель темы
- Автоматическое сохранение выбора в localStorage
- Плавные переходы между темами
- Работает на всех страницах

### Адаптивное меню
- Бургер-меню для мобильных устройств
- Закрывается при клике вне меню
- Плавные анимации

### Анимации при скролле
- Элементы появляются при прокрутке
- Используется Intersection Observer API
- Оптимизировано для производительности

### Кнопка "Наверх"
- Появляется после прокрутки вниз
- Плавная прокрутка к началу страницы
- Адаптивное позиционирование

### Прогресс-бары навыков
- Анимированное заполнение при появлении
- Визуальная демонстрация уровня владения
